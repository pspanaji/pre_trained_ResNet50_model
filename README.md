# Image Classifier using ResNet-50

## Project Overview

This project is a deep learning image classification application built using:

- TensorFlow
- Hugging Face Transformers
- ResNet-50
- Streamlit

The model is fine-tuned on a custom dataset and deployed using Streamlit.

## Features

- Upload an image
- Predict image class
- Display prediction confidence
- Streamlit Web UI

## Project Structure

```text
app.py
train.py
data_loader.py
evaluate.py
config.py
requirements.txt
```

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Model

- ResNet-50
- TensorFlow
- Hugging Face Transformers
